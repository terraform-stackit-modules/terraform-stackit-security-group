# Terraform STACKIT Security Group module

Terraform module which creates [security groups](https://docs.stackit.cloud/products/network/core-networking/security-groups/) and their rules on [STACKIT](https://www.stackit.de/en/).

[![Terraform Registry](https://img.shields.io/endpoint?url=https://registry.terraform.io/v1/modules/terraform-stackit-modules/security-group/stackit/latest)](https://registry.terraform.io/modules/terraform-stackit-modules/security-group/stackit/latest)
[![License](https://img.shields.io/github/license/terraform-stackit-modules/terraform-stackit-security-group)](./LICENSE)

This repository is not from the official STACKIT organization.

## Usage

```hcl
module "security_group" {
  source  = "terraform-stackit-modules/security-group/stackit"
  version = ">= 1.0.0"

  project_id  = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  name        = "example-sg"
  description = "Allow inbound HTTPS, allow all egress"

  rules = [
    {
      name       = "https-ingress"
      direction  = "ingress"
      ether_type = "IPv4"
      ip_range   = "0.0.0.0/0"
      protocol   = { name = "TCP" }
      port_range = { min = 443, max = 443 }
    },
    {
      name       = "all-tcp-egress"
      direction  = "egress"
      ether_type = "IPv4"
      ip_range   = "0.0.0.0/0"
      protocol   = { name = "TCP" }
    },
  ]
}
```

## Notes

- `rules` is a list of rule objects. A rule matches by `direction` (`ingress` / `egress`), by
  `protocol` (either `{ name = "TCP" }` or `{ number = 6 }`), and by `ip_range` or
  `remote_security_group_id`.
- There can only be one type of security group (stateful or stateless) per network
  interface/server — see the `stateful` variable.

## Examples
